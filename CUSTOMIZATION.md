# Customization Guide

## Safest workflow

1. Duplicate the SVG you want to edit.
2. Open it in Inkscape or another full SVG editor.
3. Do **not** change the document dimensions or `viewBox`.
4. Edit only the artwork you need.
5. Export/save as plain or standard SVG.
6. Compare the edited state on top of `base2-0.svg` to verify alignment.
7. Test every input before replacing the working copy.

## For Canva users

Canva is useful for basic shape and color changes, but complex SVG features can be flattened or altered. If an imported file behaves strangely, make the edit in Inkscape and use Canva only for concept work.

## Good candidates for future variants

- Red / black colorway
- White / black colorway
- Purple / black colorway
- Minimal no-pattern version
- Brighter pressed-state glow for streams
- Alternate topographic line density

## Before committing changes

Check:

- Base alignment
- Face-button alignment
- D-pad alignment
- Trigger / bumper alignment
- Stick-click alignment
- Transparent background
- No accidental white artboard/background
- Correct SVG filename
