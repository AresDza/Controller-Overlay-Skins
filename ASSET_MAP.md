# Asset Map

This file documents the purpose of the runtime SVGs in the skin.

| Asset | Purpose |
|---|---|
| `base.svg` | Base / compatibility artwork |
| `base2-0.svg` | Main controller base artwork |
| `base2-0-b-m2.svg` | Alternate base state involving B / M2 |
| `base2-0-b-m2-off.svg` | Off/default companion for the B / M2 alternate state |
| `base2-0-y-m1.svg` | Alternate base state involving Y / M1 |
| `base2-0-y-m1-off.svg` | Off/default companion for the Y / M1 alternate state |
| `a.svg` / `a-pressed.svg` | A button normal / pressed |
| `b.svg` / `b-pressed.svg` | B button normal / pressed |
| `x.svg` / `x-pressed.svg` | X button normal / pressed |
| `y.svg` / `y-pressed.svg` | Y button normal / pressed |
| `up-pressed.svg` | D-pad up pressed |
| `down-pressed.svg` | D-pad down pressed |
| `left-pressed.svg` | D-pad left pressed |
| `right-pressed.svg` | D-pad right pressed |
| `lb-pressed.svg` | Left bumper pressed |
| `rb-pressed.svg` | Right bumper pressed |
| `lt-pressed.svg` | Left trigger pressed |
| `rt-pressed.svg` | Right trigger pressed |
| `lt-and-rt-pressed.svg` | Both triggers pressed |
| `stick.svg` | Stick artwork/state |
| `stick-pressed.svg` | Stick-click pressed state |
| `menu-pressed.svg` | Menu button pressed |
| `switcher-pressed.svg` | Switcher / secondary system button pressed |
| `disconnected.svg` | Controller disconnected state |

## Important

The names and alignment of runtime assets may be referenced by the overlay itself. Keep them stable unless the corresponding overlay configuration is updated too.
